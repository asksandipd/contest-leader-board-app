# **App Name**: CodeContest Leaderboard

## Core Features:

- Leaderboard Display: Display a responsive, sortable leaderboard with Rank, UserName, Country (with flag), Overall Score, % System Test Cases Passed, and Overall Time (hh:mm:ss).
- Real-time Data Input: Input fields for updating player details (Name, ProbA-E scores, time taken, system test case %) with immediate leaderboard update.
- Dynamic Simulation: Simulate new contestants and alter existing details to dynamically animate leaderboard rankings.

## Style Guidelines:

- Primary color: Dark gray (#333) for the background to provide contrast.
- Secondary color: Light gray (#f0f0f0) for leaderboard rows.
- Accent: Blue (#007BFF) for interactive elements and highlighting.
- Clean, tabular layout for the leaderboard with clear column headers.
- Use country flag icons from the assets folder.
- Subtle animations for leaderboard updates, such as row highlighting or smooth transitions.
